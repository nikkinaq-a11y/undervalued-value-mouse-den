# Cozy Mouse Den

**Multimedia Communications — "Undervalued Value" project, Part 1: Materials**

## Function

A tiny pixel-art mouse companion lives in a cozy den and autonomously does calm idle activities — tending the fireplace, reading a book, watching a movie on the couch — each lasting realistically long (2–15 minutes), which a visitor can gently nudge but not force.

## Value: Contentment

The design practices contentment rather than just depicting it: there is no urgency, no scores, streaks, or notifications, no fast cuts, and nothing that demands the visitor's attention or rewards them for staying. The mouse is content whether or not anyone is watching. A visitor's only interaction is a "nudge" — clicking a zone sets a soft preference for what the mouse does next, but never interrupts what it's already contentedly doing. That gap between "influence" and "control" is where the value lives.

## Materials

Everything in `/assets/images` is build output. The originals live one directory above
this repo, and `tools/build_assets.py` reduces them all to a single 384x216 art-pixel
grid and a single shared color palette, so no element looks more pixelated than any
other.

**Room (4 states, from 2 paintings + 2 registered overlay crops)**

1. `den_bg.png` — the den, lamps lit
2. `den_bg_dark.png` — the same den, lamps down and television on
3. `tv_off.png` — overlay: the television dark (the default; click the set to turn it
   on, which fades the room to state 2)
4. `fire_a.png` / `fire_b.png` — overlay: two frames of the fireplace, alternated on a
   randomized 90–240 ms timer

**Mouse (6 poses x 2 lighting states = 12 sprites)**

5. `mouse_front.png` 6. `mouse_side.png` 7. `mouse_back.png` — standing, all 36 art px
   tall so the character never resizes as it turns
8. `mouse_walk.png` — stride frame, alternated with the side pose for the walk cycle
   (there is no seated sprite — the couch uses the painted frame below)
9. `mouse_lie.png` — reading on the rug
11. `*_dark.png` — a dimmed pass of all six, matching the room's lights-off state

**Whole-room scenes (the same room, mouse painted in)**

12. `scene_fire_1..3.png` — the mouse carrying a log to the hearth, setting it in,
    and sitting back to watch it catch
13. `scene_cocoa_1..2.png` — the mouse on the couch holding a mug, then sipping
14. `scene_couch_1..2.png` — the mouse settled on the couch, lamps up and lamps down
15. `tv_movie_1..8.png` — the television's glass, animated while a movie is on

**Holiday decorations (9 pieces x 2 lighting states = 18 sprites)**

Switched on by the **Holiday mode** switch in the top right. Cut off their flat
backdrops by `tools/cut_halloween.py`, then reduced onto the room's own art grid,
warmed and dimmed into its firelight, and given a soft contact shadow.

16. `decor_hat_1.png` — a witch's hat on the right-hand shelves
17. `decor_portrait_1/2.png` — a ghost portrait beside the round window, a witch
    portrait by the coat hooks
18. `decor_cauldron_1.png` — a cauldron on the floor at the hearth
19. `decor_pumpkin_1..5.png` — five jack-o'-lanterns: on the shelves, at the hearth,
    on the coffee table, by the couch, and one out on the floor
20. `decor_*_dark.png` — the same nine at the room's measured 0.55 dim, so they go

**Also**

21. `tools/build_assets.py` — the pipeline that produces all of the above
22. `tools/cut_halloween.py` — isolates the decoration art from its backdrops
23. `tools/read_placement.py` — reads where the decorations go back out of
    `content/reference/holiday-placement.png`, so the room is redecorated by
    moving things around in a picture rather than by editing coordinates
24. `tools/pose-spec.md` — the spec new pose art has to meet to enter the pipeline

**Sound**

**Type**

## Running it

```
python3 -m http.server 8731      # then open localhost:8731
```

That is all it needs — the site is plain HTML, CSS and JS with no build step and
no dependencies. Everything it loads is in this repo.

To rebuild the images from the original art:

```
python3 tools/build_assets.py    # needs Pillow and numpy
```

The originals live in `content/art/` **in this repo**, so a clone can regenerate
everything — and that rebuild is verified to reproduce `assets/images/` byte for
byte. See `content/README.md`.

## Putting it online

It is a static site, so GitHub Pages serves it as-is:

1. Create an empty repository on github.com (no README, no .gitignore).
2. `git remote add origin https://github.com/<username>/undervalued-value-mouse-den.git`
3. `git push -u origin main`
4. On github.com: **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**
5. It appears at `https://<username>.github.io/undervalued-value-mouse-den/`

**Before sharing it**, set `TEST_MODE = false` at the top of `script.js`. While it
is `true` the mouse changes activity every few seconds so transitions can be
watched; the real pacing is 2–15 minutes, which is the whole point of the piece.
